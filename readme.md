
# Fahh

Little plugin that plays funny sounds.



### Documentation

To enable the plugin, first go to the `autoloads` folder and make `fahh_player.gd` a global autoload named `FahhPlayer`, then enable the plugin.

I'm not a pro at plugin development, so I don't really know how to add an autoload without getting errors yet.

Thanks for trying it and feel free to play with it!

###Note
It's Windows-only for now, but there is a small section in `plugin.gd` where you can add your own custom code. I believe the plugin is cross-platform. It's a little bit messy right now, as I just wrote the whole main thing in `plugin.gd`.

###Warning
This plugin runs a batch/script file repeatedly to read logs.  
I haven't fully optimized it yet, so use it carefully in larger projects(It may crash the project...I dunno)
